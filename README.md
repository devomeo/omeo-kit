# omeo-kit

Marketplace Claude Code **mc-groupe-plugins** + plugin **omeo-kit** pour le CRM
Django Omeo.app : agents, skills et garde-fous pour coder en sécurité et sans
régression, et réduire la dépendance au développeur senior.

## Installation (équipe)

```
/plugin marketplace add https://github.com/devomeo/omeo-kit.git
/plugin install omeo-kit@mc-groupe-plugins
```

Voir `omeo-kit/README.md` pour le détail des agents, skills et commandes.
